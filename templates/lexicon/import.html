BEFORE YOU IMPORT

让词库内容可追溯。

  1. 只选择可信的本地 JSON 文件，字段格式以表单帮助信息为准。
  2. 核对释义、关联词、短语和例句的准确性，不以空缺信息推测事实。
  3. 填写可识别的来源；导入后的内容可在词汇详情页核查。
  4. 服务端校验失败时，请按错误提示修正文件，再次提交。

导入不调用外部大模型，也不会自动编造缺失释义。

JSON 格式示例

    "lemma": "learn",
