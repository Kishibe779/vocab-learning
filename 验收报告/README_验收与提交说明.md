# 验收报告阅读与提交说明

本目录已按课程任务书生成报告、8张工程图与真实自动化测试证据。**这些是基于当前实际系统的验收草稿，不是未经审核即可直接提交的学校终稿。**

## 先打开哪些文件

| 文件 | 用途 |
|---|---|
| `00_项目综合验收报告.docx` | 小组综合报告：需求、3个详细用例、非功能、架构、模块、数据库、页面、核心流程、测试、进度和提交对应 |
| `01_成员A_课程设计报告草稿.docx` | 侧重试卷分析与历年对比 |
| `02_成员B_课程设计报告草稿.docx` | 侧重词库资料、关系、短语和用法 |
| `03_成员C_课程设计报告草稿.docx` | 侧重个人学习、复习和权限集成 |
| `04_软件测试报告.docx` | 60条测试用例，含功能、步骤/输入、预期、实际、是否通过及缺陷修正记录 |
| `图件/` | 8张编号PNG工程图以及可编辑JSON说明；图片已嵌入Word报告 |
| `测试证据/测试结果.txt` | 三轮真实运行的完整输出、退出码和环境版本 |
| `测试证据/自动测试记录.json` | 可复核的逐项记录；最后一轮60/60通过，前两轮失败保留 |
| `文档结构验证.txt` | Word结构与业务规则校验记录 |
| `生成工具/` | 生成正文、图件及Word文件的源码，非网站运行必需 |

同名 `.md` 便于PyCharm查看和修改文字，同名 `.json` 是Word生成内容输入。

## 测试真实性

- 实际环境：Python3.13.7、Django5.2.17、SQLite3.50.4。
- 实际执行者为自动化工具，不冒充三名学生人工执行。
- 第一轮59通过/1失败；第一次修正后第二轮仍59通过/1失败；最终第三轮60通过/0失败。
- 缺陷为含短语JSON的合法重复导入被提前唯一验证误拒绝，现已修复并回归；非法重复资料仍应回滚。
- Django隔离内存测试库运行，不删除或覆盖你正在使用的db.sqlite3，不更改演示账号密码。
- 自动化通过不等于MySQL、浏览器设备体验、高并发或教师现场验收已完成；未执行项如实列出。

## 打印或提交前必须补齐

1. 三名成员真实姓名、学号、具体班级、指导教师与最终日期。
2. 每名成员的实际参与内容、亲自验证的操作、真实问题与个人总结；不能仅换姓名，不能虚构独立手写代码或测试。
3. 学校报告格式模板。当前采用A4、中文宋体正文、标题层级、页码与图表；未收到学校模板，不能保证完全符合专用格式。
4. 用Word/WPS打开，更新整个目录（右键目录→更新域/更新目录）；检查分页、图表清晰度后再打印。程序结构校验不替代人工打印预览。
5. 若最终切换MySQL或完善NLP/分页等功能，同步更新报告和测试，不能继续写旧版本结果。
6. 真题与词典来源未提供，当前原创演示资料已明确标注，不是历年真实考研频次结论。

## 生成工具说明

工具使用现有 .NET/OpenXML SDK 和本机Anaconda的Pillow，没有为生成报告更改全局Python包。DocBuilder.csproj当前引用本机技能目录，只适用于此电脑；成员阅读Word和Markdown不需要这些工具。如需在其他电脑再生成，应将引用改为本机可用OpenXML项目/包位置。

报告不包含README中的明文账号密码。测试账号只用于组内运行说明，不宜写入正式纸质报告。
